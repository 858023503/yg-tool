# 刷怪配置 —— 三家实现专题

> 刷怪配置：传奇服务端常用配置工具（MonGen 查看/调整 + 动态刷怪），还原自蜗牛/快捷助手/虾米。

## 一、功能

1. **刷怪查看**：MonGen.txt 全量列表（地图/X/Y/怪物/数量/范围/间隔），支持地图/怪物过滤
2. **原刷怪调整**：数量×倍数 / 时间×倍数 / 排除条件（≥/≤ 间隔、数量）
3. **动态刷怪**：触发百分比 + 人数 + 刷怪百分比 + 间隔 → MonGen 缩小 + AutoRunRobot + RobotManage（"有人有怪，无人清怪，性能节约、稳定不卡"）
4. **QManage 定时器注入**（虾米借鉴）：SETONTIMER + @OnTimer 段，自动去重

## 二、三家实现对比（详见各子目录 README）

| 实现 | 机制 | 状态 |
|---|---|---|
| **蜗牛** | Electron 字节码 `getMonGen`/`analysisNpcs`；原刷怪调整 + 动态刷怪 | 功能最全，元歌按其复刻 ✅ |
| **快捷助手** | **无刷怪功能**（exe 字符串扫描 0 命中：ASCII + UTF-16 均无 MonGen/刷怪） | 无借鉴 ❌ |
| **虾米** | Python `load_spawn_document` + `_render_existing_record`（行级局部更新）+ `_split_preserving_endings`（保留行尾） | 格式保留最严谨，元歌已融合 ✅ |

## 三、元歌工具箱实现（三合一融合）

**函数**（rate-tool/lib.js）：

```js
readMonGen(root)                              // MonGen 解析（spawns + rawLines + newline）
listMonGen(root, {map, mon})                  // 查看（-f 过滤）
adjustMonGen(root, {monCount, monDate, type, name, 排除条件})  // 原刷怪调整
genDynamicSpawn(root, {pro, count, monCount, intervaled, injectQmanage})  // 动态刷怪
injectQManageTimer(root, {label, timerId})    // QManage 定时器注入（虾米 _inject_qmanage_timer）
backupMonGen(root, tag)                       // 写前备份到 Envir/@backup/
preserveMonGenWrite(file, rawLines, newline)  // 保留换行类型 + 尾换行
```

**融合点标注**：
- 蜗牛 → 功能形态（原刷怪调整 + 动态刷怪三段式）
- 虾米 → ① QManage 定时器注入 ② 概率>0 校验 ③ 行级更新保留格式 ④ 原子写入
- 快捷助手 → 无（未参与）

**写安全**：写前自动备份 + 原子写入（临时文件+rename）+ LF/CRLF 自动保留 + 注释/分隔线不丢

## 四、CLI / GUI

```
元歌工具箱-CLI.exe mongen list <引擎根> [-f 地图|怪物]      # 查看
元歌工具箱-CLI.exe mg-adjust <引擎根> --count 2 --time 0.5   # 原刷怪调整
元歌工具箱-CLI.exe dynamic <引擎根> --pro 50 --moncount 50 [--qm]  # 动态刷怪(+QManage)
元歌工具箱-CLI.exe spawn qm <引擎根> [--label @标签]         # QManage 注入
```
GUI：侧边栏「刷怪配置」面板（原刷怪调整 + 动态刷怪 + QManage 复选框）
