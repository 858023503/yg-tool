# 虾米变量查询 —— 逆向证据 + 元歌实现（5 组变量类型版）

> 虾米工具箱「变量查询」（_VarQueryPage + _VarQueryWorker），及元歌工具箱的完整复刻。
> 证据来源：`main-structure.txt`（函数树 5100-5180）+ 用户提供虾米变量类型清单。

## 一、原版逆向结论

### 虾米可获取的变量类型（5 组，用户确认）

```
常规类型：A, G, I, J, M, N, S, P, U, T, Z（单字母 + 数字索引变量）
计时与标识：定时器（SETONTIMER/@OnTimer）, 个人标识（[N]）
输入与交互：输入字符串（INPUTSTR）, 输入整数（INPUTNUM）, ok框（MESSAGEBOX）, 自定义按钮
触发与主体：物品触发（UseItem）, HUMAN, 魔法触发（MagSelfFunc）
命名变量：N$, S$
```

### UI 结构（_build_var_* 系列）
- `_build_var_type_box`：类型树（按 5 组分类）
- `_build_var_used_box`：已用变量按钮列表（带使用次数）
- `_build_var_detail_panel`：详情表格（文件/行号）+ `_open_file_at_line`（打开定位）
- `_render_used_buttons`：重新扫描/开始扫描
- 后台扫描 worker（_scan_one_file/_detect_encoding）

## 二、元歌实现（已融合 ✅ 5 组全支持）

```js
// rate-tool/lib.js
scanVariables(root) → { groups: {
  '常规类型':   { A: {变量:[详情]}, G: {...}, I, J, M, N, S, P, U, T, Z },
  '计时与标识': { 定时器: {...}, 个人标识: {...} },
  '输入与交互': { 输入字符串, 输入整数, ok框, 自定义按钮 },
  '触发与主体': { 物品触发, HUMAN, 魔法触发 },
  '命名变量':   { 'N$': {...}, 'S$': {...} }
}, matches, files }
```

**实测**（真实端 724 文件）：
- 13907 处匹配（含单字母变量/定时器/标识/命令）
- 常规类型：A(13)/G(11)/I(1)/M(28)/N(35)/S(24)/P(2)/U(28)/T(2)
- 计时与标识：定时器(31)/个人标识(100)
- 输入与交互：输入字符串/ok框
- 触发与主体：物品触发/HUMAN/魔法触发
- 命名变量：N$(388)/S$(754)

## 三、CLI / GUI

```
元歌工具箱-CLI.exe varquery <引擎根> [--type N$] [--var 变量名]
```
GUI：侧边栏「🔍 变量查询」面板
- 18 个分组按钮（组-类型，如"常规类型-A"/"计时与标识-定时器"）
- 变量列表（带次数）+ 详情表格（文件/行号）+ 打开文件（系统默认软件）

## 四、差异

| 对比项 | 虾米 | 元歌 |
|---|---|---|
| 变量类型 | 5 组全类型 | ✅ 5 组全支持 |
| 类型树 | 树形 | 分组按钮（简化） |
| 打开文件 | Notepad++ -n | ✅ 系统默认软件（shell.openPath） |
| 详情跳转 | 选中行可打开 | ✅ 选中行 → 打开文件 |
