# 货币兑换 —— 三家实现专题

> 货币兑换：先一键提取全服货币，再配置兑换 NPC 生成，还原自蜗牛/快捷助手/虾米。

## 一、功能

1. **一键提取全服货币**：扫描 Envir 全部脚本，提取所有出现的货币名（内置 + 自定义变量）
2. **配置兑换**：货币×N 兑换 货币×M，生成 NPC（菜单显示兑换内容）
3. **命令映射**：金币单 IF（CHECKGOLD 无操作符）、GameXxx 双 IF（带操作符）、自定义变量（CHECK/DEC/INC）

## 二、三家实现对比（详见各子目录 README）

| 实现 | 机制 | 状态 |
|---|---|---|
| **蜗牛** | 版本消耗→货币花费：扫描 Envir + 命令匹配 + NPC 查询 | 元歌按其复刻 ✅ |
| **快捷助手** | **无货币兑换**（无证据） | 无借鉴 ❌ |
| **虾米** | 货币材料消耗统计（扫描 Envir + DEC 合计） | 方向一致，元歌已有消耗分析 ⏳ |

## 三、元歌工具箱实现

**函数**（rate-tool/lib.js）：`extractCurrencies / genExchangeScript / addExchangeNpc / curCmd`

```
元歌工具箱-CLI.exe currency <引擎根>
元歌工具箱-CLI.exe exchange <引擎根> --cfg 兑换.json [--count 1]
```
GUI：侧边栏「货币兑换」面板

**实测**：提取 39 种货币；兑换脚本金币/元宝逻辑正确（修复过 count 倍率 1000→10000 问题）。
