# 端口配置管理 —— 三家实现专题

> 服务端端口配置 = M2/数据库/网关（LoginGate/SelGate/RunGate）/日志服务器的全部端口。
> 核心能力：**读取全端口 → 检测冲突 → 修改/一键替换**。

---

## 一、功能是什么

传奇服务端有 50+ 个端口分散在多个配置文件：
- `Mir200\!setup.txt`：DBPort / GatePort / LogServerPort / MsgSrvPort / IDSPort / DataSaveDBPort
- 根 `Config.ini`：GatePort1-8 / DBPort1-8 / ServerPort 等
- `LoginGate\Config.ini` / `SelGate\Config.ini` / `RunGate\Config.ini`：ServerPort / GatePort
- `DBServer\dbsrc.ini`：ServerPort / GatePort / IDSPort / DataSaveDBPort

开区常见问题：端口被占用 → 需要全部改一遍 → 极易漏改导致网关连不上。工具应支持"检测 → 报红 → 一键替换"。

## 三、元歌工具箱实现

**函数**（rate-tool/lib.js）：
- `readPortConfig(engineRoot)`：遍历 7 个配置文件读取全部 `Port=数字` 键 → 实测真实端 **55 个端口**
- `writePortConfig(engineRoot, file, key, port)`：GBK 精确修改单个键
- `replacePorts(engineRoot, from, to)`：一键替换所有配置文件（实测 `5000→5001` 替换 2 个文件）
- `checkPorts(engineRoot)`：netstat 式占用检测（已有）

**关键修复**：严格匹配大写 `Port` 键 + 排除 `Support` 子串——否则 `TZSupportRenameItem`（Sup**port**）被误判为端口。

**CLI**：
```
元歌工具箱-CLI.exe portcfg <根>                       # 列出全部端口
元歌工具箱-CLI.exe portcfg <根> --file Mir200/!setup.txt --key DBPort --port 6001   # 改单键
元歌工具箱-CLI.exe portcfg <根> --replace 5000 5001    # 一键替换
元歌工具箱-CLI.exe portcfg <根> --check                # 检测占用
```

**GUI**：端口配置面板（🔧）——读取全部 / 检测占用 / 修改单键 / 一键替换。

**真实端实测**（D:\cqzs\Mirserver怀念毕业端）：55 个端口全部正确读取（DBPort=6000、GatePort=5000、RunGate 7200、SelGate 7100、LoginGate 7000、LogServer 10000、MsgSrv 4900、IDSPort 5600）。
