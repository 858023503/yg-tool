# 快捷操作 —— 三家实现专题

> 快捷操作：一键打开常用文件/目录 + NPC 列表，还原自蜗牛/快捷助手/虾米。

## 一、功能

1. **快捷文件**：18+ 按钮一键打开（NPC/刷怪/爆率/机器人/公告/数据库 等）
2. **NPC 列表**：MerChant 表格 + 地图/NPC 名过滤 + 一键打开脚本
3. **我的快捷**：自定义快捷项（localStorage 持久化）

## 二、三家实现对比（详见各子目录 README）

| 实现 | 机制 | 状态 |
|---|---|---|
| **蜗牛** | index-f856a6b2：快捷文件 30+ 按钮 + NPC 列表 + 我的快捷 | 元歌完整复刻 ✅ |
| **快捷助手** | 文件排版 ini（路径*显示名 + 拖入排序） | 拖入可借鉴 ⏳ |
| **虾米** | 快捷组队/活动入口 + PID 监控 | 无直接借鉴 ❌ |

## 三、元歌工具箱实现

**函数**（rate-tool/lib.js）：`QUICK_PATHS / readMerChant / filterNpcs / quickOpen`

```
元歌工具箱-CLI.exe quick-open <引擎根> --path 快捷项名
元歌工具箱-CLI.exe merchants <引擎根> [-map 地图] [-name NPC]
```
GUI：侧边栏「快捷操作」面板（三块布局，还原原版）
