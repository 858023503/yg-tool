# 物品管理 —— 三家实现专题

> 物品管理 = 物品备注（ItemDescList 上/下）、物品解包（UnbindList）、系统商铺（ShopItemList）、物品套装（GroupItemList）等 Envir 配置的编辑。
> 改版本必备：给物品加说明、加解包、调商铺、配套装。

---

## 一、功能是什么

物品相关配置文件（快捷助手"文件排版"清单）：
- `ItemDescTopList.txt`：物品备注-上（名字上方，可含 `<img>` 富文本）
- `ItemDescList.txt`：物品备注-下（格式 `物品名=\颜色码/文本`，\243 灰 \249 黄 \251 绿 \253 蓝）
- `UnbindList.txt`：物品解包（`物品ID 物品名`）
- `ShopItemList.txt`：系统商铺（`商店类型 物品名 价格 ...`）
- `GroupItemList.txt`：物品套装（`组ID 类型 触发物品 组成(用|分隔) 属性40列×4`）
- 其他：MonSayMsg 怪物说话 / MonSpAbilList 怪物元素 / RevivalItemList 复活戒指 / ParalysisItemList 麻痹戒指 / MagicShieldItemList 护身戒指 / GuardList 大刀卫士

## 二、三家实现对比

| 实现 | 机制 | 状态 |
|---|---|---|
| **快捷助手** | 文件排版清单内置 20 个快捷文件（含物品类 5 个），快速打开编辑 | 目录式，元歌已吸收清单 |
| **蜗牛** | 物品库管理（用户评估后跳过）——未深入 | 未采用 |
| **虾米** | 版本数据含"数据库管理/爆率管理/存销设置/回收生成"，物品备注/套装在资源文件区 | 功能页多为占位（"尚未接入"） |

## 三、元歌工具箱实现

**函数**（rate-tool/lib.js）：
- `readItemDesc/writeItemDesc/addItemDesc/delItemDesc(engineRoot, top, ...)`：备注（上/下），颜色码分段解析——实测下 **118 条**/上 **1 条**
- `readUnbindList/writeUnbindList/addUnbindItem/delUnbindItem`：解包——实测 **24 条**
- `readShopList`：系统商铺——实测 **25 条**
- `readGroupItems`：物品套装（复杂 6 列，读+展示）——实测 **17 组**

**CLI**：
```
元歌工具箱-CLI.exe itemcfg <根>                       # 备注(下)列表
元歌工具箱-CLI.exe itemcfg <根> --top                 # 备注(上)列表
元歌工具箱-CLI.exe itemcfg <根> --add 物品 --color 249 --text 说明   # 加备注
元歌工具箱-CLI.exe itemcfg <根> --del 物品            # 删备注
元歌工具箱-CLI.exe itemcfg <根> --unbind              # 解包列表
元歌工具箱-CLI.exe itemcfg <根> --unbind --add 999 物品名   # 加解包
元歌工具箱-CLI.exe itemcfg <根> --shop | --group      # 商铺/套装
```

**GUI**：物品管理面板（🎒）——备注上/下/解包/商铺/套装切换 + 添加/删除。

**真实端实测**：沃玛号角=`\243/创建行会材料`、祝福油=`\243/给武器增加6点幸运\243/幸运9套可发挥最高威力` 等解析正确。
