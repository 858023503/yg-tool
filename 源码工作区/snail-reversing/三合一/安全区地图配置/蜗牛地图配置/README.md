# 蜗牛地图配置 —— 逆向证据

> 来源：蜗牛实用工具 REVERSE-REPORT.md（渲染进程功能清单）

## 证据

蜗牛有**地图**功能：
- **地图（MapInfo.txt）**：地图配置编辑
- **地图安全区**：安全区配置
- **宝箱数据**（BoxsDir/BoxsFile）、假人列表、Robot 机器人脚本
- **素材资源目录管理**（缺失提示/占位图）、多颜色选择器

## 结论

蜗牛有 MapInfo/安全区相关功能，但**未见独立的地图配置面板**（功能集成在数据管理区）。元歌实现了独立的地图配置面板（StartPoint 增删查/MapInfo 属性+传送门解析/MiniMap 读写，快捷助手文件排版路线）。
