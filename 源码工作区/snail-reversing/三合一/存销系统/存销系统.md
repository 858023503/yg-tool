# 存销系统 —— 三家实现专题

> 存销系统：服务端数据打包 / 存销脚本生成，还原自蜗牛/快捷助手/虾米。

## 一、功能

1. **数据打包**（蜗牛形态，元歌已实现）：物品数据 → 掉落数据 → 刷新地图数据 → 存储数据 → 完成
2. **配置项**：生成路径（多区建议 D 盘根目录）、数据目录名（默认同服名）、处理爆率格式（新爆率/原版）、新爆率分组数（个/组）、用户编号（数字/字母/数字+字母）、版本引擎（凌风系/GOM系）
