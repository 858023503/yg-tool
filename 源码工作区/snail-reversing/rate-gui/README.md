# 爆率修改工具（GUI 版）— 使用说明

双击 **`爆率修改工具.exe`** 即可打开图形界面，无需安装任何环境。
（便携版：exe 与同目录下的 dll/locales 等文件需保持在一起，整个文件夹可复制到任意位置。）

## 界面操作

1. **选引擎根目录**：点「浏览…」选择传奇服务端目录（含 `Mir200\Envir\MonItems`）
2. **选范围**：`全服（所有怪物）` 或 `指定怪物`（填怪物名，如 白野猪）
3. **选操作**：`追加爆率`（填物品名、概率、数量）或 `删除爆率`（填物品名）
4. 点 **「执行修改」**，底部日志区显示每个文件的处理结果

| 项 | 含义 |
|---|---|
| 爆率 | 每 N 只怪掉 1 个（如 100 = 1/100） |
| 数量 | 一次最多掉几个（默认 1） |
| 追加 | 在爆率文件末尾加一行，如 `屠龙 1/100 1` |
| 删除 | 移除所有该物品的爆率条目 |

**「备份 MonItems」**：修改前点一下，把 `MonItems` 整目录复制成 `MonItems.bak-<时间戳>` 备份。

## 与还原的关系

- 核心算法从「蜗牛实用工具 6.3.2」preload 字节码完整还原（解析/概率计算/序列化，见 `REVERSE-REPORT.md` 第九章）
- 本工具是独立实现，不含原工具任何网络/授权逻辑，纯本地文件操作

## 命令行版

同目录下 `rate-tool\` 提供命令行版（`node main.js` 或 `爆率修改工具.exe` 单文件 SEA 版）：
```
list <引擎根> [怪物名]             查看爆率
add <引擎根> <怪物名|*> <物品> <概率> [数量]   追加
del <引擎根> <怪物名|*> <物品>      删除
backup <引擎根>                   备份
```
