## 四、已知正常行为（别当 bug 报）

1. **批量调整-随机爆率**输出这种格式是**正确的**（对齐原版蜗牛 + 真实端引擎）：
   ```
   #CHILD 1/100 RANDOM
   (
   1/1	书页
   )
   ```
   ——**不是** `#CHILD 1/100 RANDOM 书页`（行内物品格式引擎不认）
2. **随机转换**只转换**组外**的普通条目，原 `#CHILD ... RANDOM ( ... )` 组保持原样
3. **`金币2000` 连写**（无空格）是完整物品名，引擎认；物品查询搜"金币"查不到它属正常
4. **倍率语义**：`批量调整 倍率 2` = 分母×2（`1/100 → 1/200`，掉率减半）；`倍率 0.5` = 掉率翻倍
5. **操作日志**在页面最底部（吸底显示），所有功能结果统一走那里，面板内没有输出框是设计如此
6. 生成脚本里的品牌是「元歌」（如 `[@元歌一键回收]`），**没有** QQ 群/蜗牛/引流——这是刻意要求
