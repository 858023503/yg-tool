# 「全局修改爆率」功能 —— 业务逻辑说明

> 来源：对 `蜗牛实用工具6.3.2` 的渲染层 JS（明文）+ preload 字节码（Ignition 反汇编）的完整还原
> 还原时间：本次会话；证据：`setrate-bc.hex`、`SFI13347-bc.hex`、`preload-funcs-pseudocode.txt`

---

## 1. 功能在用户界面长什么样

用户选择要改的**引擎根目录**（`e.node.path`，即传奇服务端 Mir 目录），然后指定三件事：

| 表单项 | 取值 | 含义 |
|---|---|---|
| 范围 `f.type` | `all` / `map` / `allmongen` / `goods` | 全服 / 按地图 / 按怪物名 / 按物品 |
| 操作 `f.style` | `append` / 非append | 追加爆率 / 删除爆率 |
| 目标列表 `f.names` | 怪物/地图名数组 | 只对指定的目标生效 |

提交后底部提示 **"完成修改，共用时 N 秒"**。

## 2. 一次"全服追加爆率"的完整调用链

```
[渲染层 index-2e363a07.js]  Vue 表单提交函数
   │  f.type === "all"
   ├── window.rate.setRate(引擎根, [], true)          // files=[] 表示全服，append=true
   │        │
   │        ▼  [preload 字节码]
   │     SFI#13335（setRate 闭包）
   │        │  ① 参数落槽：files 缺省→[]，append 缺省→true
   │        ▼
   │     SFI#13347（内部辅助函数，86B 字节码）
   │        ① 路径拼接：String(闭包变量) + '\Mir200\Envir\MonItems'   ← 爆率目录
   │        ② 再拼接一份存到 r1
   │        ③ 取模块级对象（深层上下文槽）→ 取 copyDir 方法
   │        ④ 调 copyDir(拼接路径, ...)                 ← 读取/备份爆率目录
   │        ⑤ 取 indexRate 模块方法 → 解析爆率文件 → 返回 JSON 数据
   │        │
   │        ▼  （Promise resolve，数据回到渲染层）
   ├── updateItems.setUpdateItems(JSON.stringify(数据), JSON.stringify(表单))
   │        │
   │        ▼  [preload updateItems 模块 = updateGoods 类]
   │     把修改后的爆率数据写回 MonItems\*.txt
   │
   └── 日志模块 l.setAppends / l.setRemoves（记录追加/删除操作）
          → 提示"完成修改，共用时 N 秒"
```

其他三种范围的差异只发生在**调用 setRate 前**：

- **按地图**（`map`）：先查 `MonGen.txt`（该地图刷哪些怪），把怪名拼成 `怪物名.txt` 列表再调 `setRate`
- **按怪物名**（`allmongen`）：直接把 `f.names` 拼成 `怪物名.txt` 列表
- **按物品**（`goods`）：`setRate(路径)` 不传文件列表，走 updateGoods 单独处理

## 3. 核心数据结构与文件格式

- **爆率文件**：`<引擎根>\Mir200\Envir\MonItems\<怪物名>.txt`（每怪物一个文件，传奇引擎标准爆率表）
- **MonGen.txt**：`<引擎根>\Mir200\Envir\MonGen.txt`，记录地图刷怪配置，用于"按地图"时反查怪物
- **setRate 返回值**：解析后的爆率数据（JSON，供 UI 展示与修改）
- **写回**：`updateGoods.setUpdateItems(数据JSON, 表单JSON)` 把修改后的数据序列化回文件

## 4. 从字节码还原的实现细节

setRate 闭包（SFI#13335）真实指令流要点：

```
CreateFunctionContext(2槽)
ctx[2] = 参数3          // files
ctx[3] = 参数4 或 []    // files 缺省默认空数组（全服）
ctx[4] = 参数5 或 true  // append 缺省默认 true
try {
  块上下文；调 常量池[3] 属性（模块方法）
  r5 = global[常量池5]  // indexRate 模块
  r6 = CreateClosure[常量池6]   // 回调闭包
  acc = new 模块(闭包...)       // 实例化处理对象
} catch (e) {
  SetPendingMessage; 异常处理
}
```

辅助函数（SFI#13347）真实指令流要点：

```
ctx[2] = 参数
ctx[3] = String(闭包变量) + 常量池[2]        // 常量池[2] = '\Mir200\Envir\MonItems'
r1    = String(闭包变量) + 常量池[3]          // 常量池[3] = ['\Mir200\Envir\MonItems\']
r5    = 深层闭包变量（模块级共享对象）
r4    = r5.copyDir                            // 常量池[5] = "copyDir"
acc   = r4[常量池[4]](ctx[3], ...)            // 调用 copyDir(爆率目录, ...)
r3    = r4[常量池[6]]                         // 取下一方法
r5    = CreateClosure[常量池[7]]              // 回调闭包（SFI#13353）
acc   = r3[常量池[8]](r4, r5)                 // 执行
return undefined
```

**还原出的关键字符串常量**（直接来自 .jsc 序列化对象流）：

| 对象 | 值 | 用途 |
|---|---|---|
| #13351 | `\Mir200\Envir\MonItems` | 爆率文件目录（相对引擎根） |
| #13352 | `[\Mir200\Envir\MonItems\]`（数组字面量） | 拼接用目录数组 |
| #9368 | `copyDir` | 目录读取/备份方法名 |
| #1891 | `toLowerCase` | 怪物名规范化（.txt 文件名） |
| #9579 | `setRate` | 导出 API 名 |
| #1468 | `map` | 范围类型名 |
| #13228/#13350 | ScopeInfo（作用域变量表） | 闭包变量元数据 |

## 5. 还没挖到的一层

`setRate` 的**真正解析/写回算法**在更深的两处：

1. **`indexRate` 模块**（`require('mf').indexRate`）——爆率文件格式解析器（MonItems\*.txt → JSON）
2. **`updateGoods` 类**（`require('updateItems').updateGoods`）——修改数据 + 写回文件

这两者都是 preload 字节码内部的模块（SFI#13229/#13237/#13258/#13277/#13303 之一），
不在渲染层明文里，需要用同样的 Ignition 反汇编方法继续挖（操作码表已就绪）。
