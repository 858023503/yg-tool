# 爆率修改工具 — 使用说明

一款独立的传奇引擎（Mir200）爆率修改工具。
核心算法（爆率解析、概率计算、序列化写回）**从「蜗牛实用工具 6.3.2」的 preload 字节码完整逆向还原**（详见上级目录 `REVERSE-REPORT.md` 与 `爆率功能业务逻辑.md`）。

## 文件

- `爆率修改工具.exe` — 单文件可执行程序（Node.js SEA 打包，无需安装任何环境，双击/命令行直接用）
- `lib.js` / `main.js` — 可读源码（Node.js 版，`node main.js` 等效）
- `test.js` + `test-mir\` — 自带模拟爆率目录，用于验证

## 命令

```
爆率修改工具.exe list <引擎根目录> [怪物名]              查看爆率（缺省列出全部怪物）
爆率修改工具.exe add <引擎根> <怪物名|*> <物品> <概率> [数量]   追加爆率
爆率修改工具.exe del <引擎根> <怪物名|*> <物品>          删除某物品爆率
爆率修改工具.exe backup <引擎根>                       备份 MonItems 目录
```

## 示例

```
# 查看白野猪的爆率
爆率修改工具.exe list D:\MirServer 白野猪

# 给白野猪追加爆率：每 100 只掉 1 个屠龙
爆率修改工具.exe add D:\MirServer 白野猪 屠龙 100 1

# 全服追加（* = 所有怪物文件）：每 500 只掉 1 个裁决之杖，最多 2 个
爆率修改工具.exe add D:\MirServer * 裁决之杖 500 2

# 全服删除屠龙爆率
爆率修改工具.exe del D:\MirServer * 屠龙
```

## 说明

- 引擎根目录 = 传奇服务端目录（其中含 `Mir200\Envir\MonItems\<怪物名>.txt`）
- 怪物名不区分大小写（还原自 `toLowerCase` 逻辑）
- 爆率文件格式（传奇标准）：
  - `物品名 1/100 1` — 每 100 只怪掉 1 个
  - `物品名 5/10 3` — 10 只怪掉 5 个、最多 3 个
  - `#CHILD 1/50 2` — 子项
- 概率计算逻辑还原自原工具：概率值×数量 → 最小值 1 → 上限 90000000 → round 取整
- **操作前建议先 `backup`**，本工具不会自动备份
