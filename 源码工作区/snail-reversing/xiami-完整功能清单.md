# 虾米工具箱 完整功能清单（逆向整理）

> 来源：`D:\传奇工具\虾米工具箱`（Python 3.8 + PySide2 打包，`虾米工具箱.pkg` 解包 20001 流分析）
> 主窗口标题：虾米工具箱 - Dark Workbench；需要邮箱注册登录（会员制，登录解锁功能）

---

## 一、账号与基础框架
- 邮箱注册 / 登录 / 验证码 / 记住密码 / 会员到期管理
- 授权状态左下角显示；未登录功能锁定
- 全局根目录选择（Mir200/Mud2 自动识别）

## 二、基础工具（根目录下集中处理）
- **文本搜索**：输入关键字搜索版本脚本和配置文本（脚本/配置/物品/怪物/变量关键字）
- **端口配置**：
  - 读取 Config.ini 端口配置
  - 按规则生成端口（自动端口/列表端口）
  - 检测端口占用（本地/外网可达性，含内网 IP 无法外访提示）
  - 保存端口与基础参数（网关/数据库/角色网关/服务端/微端端口）
- **文件对比**：左右两文件文本对比，快速定位变更
- **货币兑换**：见下

## 三、货币兑换（兑换 NPC 生成）
- 兑换 NPC：地图 / 名称 / 坐标（X 空格 Y）
- **多条兑换规则**（消耗货币 → 获得货币，可增删行）
- 货币类型：内置（元宝等）+ **自定义货币变量**
- **货币变量参考显示**（读取 Mir200 货币变量）
- **货币材料消耗统计**（扫描 Mir200\Envir，检查货币变量/兑换规则/脚本消费结果，自定义变量 DEC 合计）
- 写入 MerChant.txt 商人配置 + 生成主脚本

## 四、爆率设置
- **新增爆率**：MonItems 全怪物追加，物品列表搜索多选自动填入
- **整体爆率优化**：全服爆率 ×N（如 ×0.8），带备份
- **二级爆率优化**：#CHILD 子项优化，带备份
- **普通爆率分组**：分组处理/备份
- **指定删除**
- **一键恢复备份**（整体/二级/分组/新增/删除 各类型备份）
- **爆率查询导出**：导出爆率数据（单个查询项或全部）

## 五、刷怪设置
- **MonGen 表格编辑**：加载 MonGen.txt 后表格直接编辑数量/时间/地图，筛选、批量修改、删除，立即保存
- **动态刷怪**：触发概率/触发人数/刷怪概率/间隔/清怪间隔/缺怪阈值
- **个人刷怪**：检测范围/怪物少于阈值/刷怪范围/最少数量（玩家周围怪少自动刷怪），生成"虾米个人刷怪"脚本
- **副本刷怪**：按刷怪表生成副本刷怪脚本
- **虾米刷怪定时**：定时刷怪脚本

## 六、脚本注入
- **模板注入**：TXT 模板格式（多脚本条目），追加(创建)/覆盖，目标文件路径
- **物品注入**：数据库物品库识别，模板批量配置物品
- **变量冲突检测与替换**：
  - 替换版本内占用变量（改版本原脚本冲突变量）
  - 替换注入脚本内占用变量（只改模板内容）
  - 变量类型多选（个人变量/全局变量等）
  - 同一模板关联脚本统一替换保持联动
- 一键注入 / 一键删除注入 / 备份恢复

## 七、变量查询
- 扫描 Envir 查看变量占用
- **点击变量定位引用文件和使用位置**
- 自定义变量 DEC 合计
- 变量防重复文件（防重复.txt）

## 八、存销设置
- 脚本名 / 方法名 / 分类目录 / 按钮编号 → 生成存销目录结构并自动注入相关脚本
- 存销变量初始化（变量初始化.txt）
- **2PC 事务**（提交/回滚/备份/校验/恢复，防外部修改）
- 存销生成备份 / 一键删除备份

## 九、回收生成
- 多类别回收 / 分解 / 经验
- **自动回收开关**（挂接个人定时器）
- **回收系数/回收倍数**（货币回收加成）
- 回收货币 / 回收经验 / 一键回收 / 今日回收（次数记录）
- 回收设置：保存/加载/恢复默认
- 控制变量配置 + 生成回收脚本一键复制

## 十、微端配置
- 微端模板选择/保存
- 创建微端（微端密码/端口/目录，复制模板）
- 微端程序 / 微端网关 配置
- 启动/关闭/隐藏/显示微端窗口
- 刷新微端运行状态
- 免费微端 / 微端链接地址 / 轻量微端备用包

## 十一、PAK 素材
- **PAK 密码加密服务**（在线请求加密）
- 选择 PAK 文件或 pak.txt，复制 PAK 文件
- 素材目录复制（绝对盘符路径）

## 十二、编码转换
- TXT 批量编码转换（UTF-8 / GBK / GB18030 / UTF-16 BOM）
- 源编码识别 + 目标编码，**严格往返校验**（防乱码）
- 转码前备份原始文件（封挂编码）

## 十三、CDK / 卡密
- **CDK**：类型管理（新增/删除）、字符长度/数量/字符集、批量生成保存、未使用/已使用列表、查询、核销归档、兑换 CDK
- **卡密**：生成/导入（逗号/空格/换行分隔）、库存（全部/已兑换/未兑换）、兑换积分、卡密修改/重置/删除

## 十四、数据库管理
- 自动识别数据库（文本库 / SQLite）
- 浏览/搜索/编辑/批量修改/导入/导出/备份/压缩数据表
- 物品库（物品名识别，用于物品注入）

## 十五、网站管理（发布站）
- 创建传奇发布站：首页 / 简介 / 下载地址 / QQ群 / 版本展示
- **爆率查询页面**（导出爆率数据到网站）
- 登录器下载中心（版本/登录器直链/补丁包/备用登录器/历史版本）
- 本地预览首页与爆率页后再发布
- 网站目录固定为工具箱同级 Website 文件夹

## 十六、登录器
- 选择登录器 exe 或快捷方式，启动并监控 PID
- 登录器与补丁下载中心

## 十七、QQ 机器人（embedded_xiami 插件，Dark Workbench）
- AI 知识问答 / 签到积分 / 答题积分 / 卡密兑换 / 账号绑定 / 自定义回复 / 好友审核 / 入群审核 / 群管（禁言踢人）/ 名单与违禁词 / 邀请积分 / 本地知识库 / 权限管理 / 群配置 / OneBot 工具 / 菜单帮助
