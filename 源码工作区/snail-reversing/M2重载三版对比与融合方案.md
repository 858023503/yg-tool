# M2 重载 三版实现对比（蜗牛 / 快捷助手 / 虾米）→ 融合方案

## 一、三款实现机制（结论先行）

三款 **本质相同**：Win32 菜单点击——找 M2 主窗口 → GetMenu 枚举"控制→重新加载"菜单 → 匹配项 → PostMessage WM_COMMAND(菜单ID) 模拟点击。
差异在 **找进程、找窗口、菜单路径解析** 三个环节的实现精度。

## 二、逐环节代码对比

### 1. 找 M2Server 进程

| 版本 | 实现 | 代码依据 |
|---|---|---|
| 快捷助手 | 未明确（VB6 直接 FindWindow 标题找窗口） | 导入 FindWindow/FindWindowEx |
| 蜗牛 | 按 M2Server.exe 路径枚举 PID | 常量池 `\Mir200\M2Server.exe` + `[pids] loadM2 error:` + getPid |
| **虾米** | **Toolhelp32 进程快照 + QueryFullProcessImageNameW 精确匹配 exe 路径** | `_iter_pids_by_exe_path`: `PROCESSENTRY32W` / `QueryFullProcessImageNameW` / `'m2server.exe'` |

**虾米最稳**：不走进程名（可能撞同名），按 exe 真实路径匹配。

### 2. 找 M2 主窗口

| 版本 | 实现 | 代码依据 |
|---|---|---|
| 快捷助手 | FindWindow 按标题（`显示M2窗口标题` 可配置） | 导入 FindWindow |
| 蜗牛 | EnumWindows 按 PID 过滤 | 常量池 `EnumWindows` |
| **虾米** | EnumWindows + **EnumChildWindows**，按 标题/类名 匹配（`_find_engine_hwnd_for_reload(title_contains, class_name)`） | `_find_engine_hwnd_for_reload` |

**虾米最全**：含子窗口（M2 嵌入 GameCenter 控制台时顶层枚举不到——正是用户提示过的场景）。

### 3. 菜单枚举与路径解析

| 版本 | 实现 | 代码依据 |
|---|---|---|
| 快捷助手 | GetMenu → 枚举"控制"→"重新加载" → GetMenuItemID | 导入 GetMenu/GetSubMenu/GetMenuItemID/GetMenuString |
| 蜗牛 | getMenus(pid)：GetMenu/GetMenuItemCount/GetMenuStringA 全树枚举 | 常量池 `getMenus` / `M2Menus` / `clickMenus` |
| **虾米** | `_enumerate_leaf_menu_items` 递归，**`>` 分隔路径**（`'控制>重新加载'` 基准 + leaf） | `_enumerate_leaf_menu_items` / `_resolve_reload_menu_path` / `strs: '控制>重新加载'` |

**虾米最优雅**：递归枚举所有叶节点，路径用 `>` 拼接，任意深度菜单可点。

### 4. 点击发送

| 版本 | 实现 |
|---|---|
| 快捷助手 | PostMessage WM_COMMAND(菜单ID) |
| 蜗牛 | clickMenus(pid, 路径) → PostMessage WM_COMMAND |
| 虾米 | 同（WM_COMMAND） |

三款完全一致：**PostMessage(hwnd, WM_COMMAND, menuID, 0)**。

### 5. 重载项定义

| 版本 | 实现 |
|---|---|
| 快捷助手 | **静态命令表 16 项**（怪物爆率:ReloadMonItems / NPC脚本:ReloadNpc / 机器人脚本:ReloadRobot ...）|
| 蜗牛 | **服务器远程下发**（本地无完整表）|
| 虾米 | `_get_reload_menu_button_defs` 动态按钮定义（从实际菜单枚举）|

## 三、融合改进方案（应用到元歌工具箱 m2-reload.ps1）

现有实现（GameCenter/M2Server 进程 + 顶层/子窗口 + 菜单项数过滤 + 22 项匹配 + WM_COMMAND）已融合"子窗口"思路。**再吸收三款长处**：

1. **【虾米】Toolhelp32 精确 PID**：CreateToolhelp32Snapshot + Process32FirstW/NextW + QueryFullProcessImageNameW 匹配 `m2server.exe` 真实路径（替代 Get-Process -Name，防同名误中）
2. **【虾米】根目录猜引擎**：GUI 传引擎根目录（Config.ini/Mir200/Envir 存在性）→ 定位 M2Server.exe 路径 → 精确匹配
3. **【虾米】`>` 路径递归**：枚举全部叶节点菜单，支持任意深度（当前已支持"控制→重新加载"两级，改为递归全树）
4. **【蜗牛】按 PID 全窗口枚举**：已实现（EnumWindows 按进程过滤）
5. **【快捷助手】命令表**：保留 22 项菜单匹配 + 关键词映射（NPC脚本→所有NPC 等）

## 四、结论
- 快捷助手：命令表映射思路（最直接）
- 蜗牛：按 PID + 菜单文本路径（FFI 封装，最工程化）
- 虾米：进程路径精确匹配 + 子窗口 + 递归路径（**三款中实现最严谨**）
- 融合后 = 虾米的进程/窗口查找 + 蜗牛的按 PID 枚举 + 快捷助手的命令表 + 我们的跨引擎兼容
