# 元歌工具箱 · 完整功能清单 + 快捷入口

> 版本：2026-08 融合版（吸收蜗牛/快捷助手/虾米三家优点）

## 一、GUI 侧边栏（25 个功能面板）

### 🔥 爆率类
| 面板 | 功能 | 说明 |
|---|---|---|
| 爆率调整 | 单怪爆率增删改 | 查看/添加/删除某怪物的爆率（概率/数量/条件） |
| 批量调整 | 全服/按怪批量改爆率 | 倍率调整、范围过滤、随机爆率转换（#CHILD） |
| 随机转换 | 爆率转随机组 | 普通爆率转 `#CHILD 1/N RANDOM` 随机组格式 |
| 按地图 | 地图刷怪+爆率概览 | 查看地图刷了哪些怪+每怪爆率文件概况 |
| 物品查询 | 物品被哪些怪掉落 | 全服扫描某物品的出处（如 书页→293 怪） |

| M2 重载 | 重载 M2 配置 | 点 M2"控制-重新载入"菜单（怪物爆率/NPC/数据库等 22 项），含懒加载预热 |

## 二、CLI 快捷入口（元歌工具箱-CLI.exe）

```
# 爆率
list <根> [怪物名]             查看爆率
add <根> <怪|*> <物品> <概率> [数量] [--child] [--after] [--range]  添加爆率
del <根> <怪|*> <物品>          删除爆率
adjust <根> <怪|*> <倍率> [--min] [--max] [--limit] [--child]  批量调整
random <根> <怪|*> [--min] [--max]  随机爆率转换
map <根> <地图>                查看地图刷怪
find <根> <物品>               查询物品掉落
backup <根>                    备份 MonItems

# 刷怪/服务端
mongen list|add|del <根> ...    MonGen 操作
mg-adjust <根> --count 倍 --time 倍 [--map|--mon]  原刷怪调整
dynamic <根> --pro 50 --count 2 ...  动态刷怪
robot list|add|del <根> ...     机器人脚本
m2reload --list|--item x         M2 重载
health <根>                     一键体检
engineck <根>                   引擎识别+健检

# 货币
currency <根> [--top N] [--drop-qf]  货币分析
exchange <根> <地图> <X> <Y> <NPC名> <消耗> <数量> <获得> <数量> [--count]  生成兑换NPC
recycle <根> <地图> <X> <Y> <NPC名> ...  生成回收NPC
sales <根> [--out 目录]         存销数据

# 工具
grep <根> <搜索> [--replace] [--nocase]  脚本搜索替换
inject <根> <名称> <QF|QM|路径> <脚本> [--mode] [--vars]  脚本注入
ports <根>                      端口占用检测
portcfg <根> [--list|--file x --key y --port N|--replace a b|--check-dup|--preset-save 名|--preset-apply 名]  端口配置
sync <根> --host x --user x --pass x [--rule]  FTP 同步

# 配置管理（新）
itemcfg <根> [--top] [--add 物品 --color N --text 说明] [--del 物品] [--unbind [--add ID 名] [--del ID]] [--shop] [--group] [--file 复活戒指]  物品管理
mapcfg <根> [--start [--add 地图 X Y 范围 类型] [--del 地图 X Y]] [--mapinfo --filter 关键字] [--minimap] [--mapevent]  地图配置
cmp <目录A> <目录B> [--max 行数]  文件对比
site <根> [--title 标题] [--skin dark|gold|blue|green|light] [--new 新区] [--fast 快餐] [--solo 单职业]  开区网站
gmcmd <根>                      游戏命令列表
```

## 三、快速上手

1. **开区前体检**：GUI → 一键体检 → 解决所有 ❌（目录键/端口重复/文件缺失）
2. **配端口**：端口配置 → 读取 → 检查重复 → 冲突就一键替换
3. **调爆率**：爆率调整/批量调整（全服倍率/单怪）
4. **加 NPC**：货币兑换（提取货币→生成）、回收生成（分类回收）
5. **改配置**：物品管理（备注/解包）、地图配置（安全区/传送门）
6. **运行中调整**：M2 重载（不重启引擎直接重载爆率/NPC）
7. **多版本对比**：文件对比（改版前后差异）
