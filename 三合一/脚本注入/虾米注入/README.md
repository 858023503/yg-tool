# 虾米注入 —— 逆向证据 + 元歌对照

> 虾米工具箱「一键注入」，及元歌工具箱的对照。
> 完整证据见 `证据-stream0014字符串.txt`。

## 一、原版逆向结论

**模块**：主程序「一键注入」

```
[注入] 先选模板或新建模板，再配置追加/复制项、地址、关键字和脚本内容，最后执行一键注入
[注入] 同模板重复注入时，工具箱会优先替换本模板旧注入块
[注入] 根目录选错、关键字定位错误、历史旧注入残留、变量冲突或关联脚本替换策略...
```

**关键设计**：
1. **模板概念**：先选/新建模板，再配置注入项
2. **追加/复制项**：注入项可追加或复制
3. **防重复**：同模板重复注入 → 优先替换旧注入块（对齐蜗牛"覆盖注入"）

## 二、元歌对照

| 对比项 | 虾米 | 元歌 |
|---|---|---|
| 模板管理 | 模板库（选/新建） | 注入项列表（名称+内容） |
| 防重复 | 替换本模板旧注入块 | isInjected + 三模式选择 ✅ |
| 变量冲突 | 有提示 | extractVars/replaceOccupyVars ✅ |

**可借鉴（未融合）**：虾米模板库概念——元歌注入项已是"名称+内容"结构，可加"模板保存/加载"。
