## 一、原版逆向结论

**模块**：主程序导航「登录脚本/触发脚本/NPC目录/**机器人脚本**/任务脚本/物品备注/物品套装/资源文件/NPC列表/刷怪...」

```
[机器人脚本] Robot 机器人脚本
[定时] 按钮号/方法名/目录名或定时器冲突会导致存销按钮失效、脚本串线或旧功能被覆盖
```

**关键设计**：机器人脚本为**编辑器/导航入口**（文件打开），定时器冲突检查提示贯穿存销/注入。
