# 虾米FTP同步 —— 逆向证据 + 元歌对照

> 虾米工具箱「同步」相关功能核查。
> 完整证据见 `证据-stream0014字符串.txt`。

## 一、逆向结论：虾米**无 FTP 同步**直接证据

**证据**：
```
[同步] 批量生成保存读取和回收 CDK...
[同步] 使用前备份服务端脚本数据库和配置目录...
```

虾米「同步」指 CDK 核销同步/授权状态同步（非 FTP 文件同步）。

## 二、对元歌的借鉴

- CDK 管理/核销同步——与元歌 FTP 同步是不同方向（元歌不需要 CDK）

## 三、元歌对照

元歌 FTP 同步 = 蜗牛远程脚本服务器复刻（文件级同步），虾米无此功能。
