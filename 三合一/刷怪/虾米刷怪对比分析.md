# 虾米刷怪对比分析（更新版）

> 对比对象：虾米工具箱「刷怪设置」 vs 元歌工具箱「刷怪配置」（原刷怪调整 + 动态刷怪 + 刷怪表格 + 个人/副本刷怪）
> 融合进度：P0/P1 ✅ + 刷怪表格 ✅ + 个人刷怪 ✅ + 副本刷怪 ✅

## 虾米核心逻辑（已还原，函数来自 main-structure.txt —— _SpawnToolLite 类）

### 1. `_apply_dynamic_spawn` —— 动态刷怪（P0-2 已融合 ✅）
- 校验："触发概率必须大于 0，否则动态刷怪永远不会触发"、"刷怪概率必须大于 0，否则不会生成有效刷怪"
- cfg: trigger_percent / spawn_percent / trigger_people
- merge_label（[@标签] 段去重合并）+ upsert_autorun（#AutoRun NPC SEC 去重）

### 2. `_inject_qmanage_timer` —— QManage 定时器注入（P0-1 已融合 ✅）
- 正则：`SETONTIMER\s+(\d+)\b` + `\[\s*@OnTimer\s*(\d+)\s*\]`（收集已用 id）
- next_id(t)：取未占用 id
- 注入 SETONTIMER + [@OnTimer id] 段（调用 call_label）

### 3. `_generate_personal_spawn` —— 个人刷怪（本轮已融合 ✅）
- 目录：`QuestDiary\虾米个人刷怪`
- 编码：win/gb18030 + \r\n
- 元歌实现：`genPersonalSpawn(root, {map, monster, count, range, injectQmanage})`
  - QuestDiary\元歌个人刷怪\<地图>.txt（CHECKMAPMONCOUNT + MONGEN）
  - 自动 QManage 定时器注入（去重）

### 4. `_generate_instance_spawn` + `_copy_map_alias_files_for_instance` —— 副本刷怪（本轮已融合 ✅）
- 目录：`QuestDiary\虾米副本刷怪`
- 地图实例：Mir200\Map + MapInfo.txt + 副本地图 + .map（缺少实例 .map 时从主图复制）
- 元歌实现：`genInstanceSpawn(root, {map, monster, count, range})`
  - 识别 MapInfo.txt `[实例|主图 名称]` 副本地图（detectDungeonMaps）
  - QuestDiary\元歌副本刷怪\<地图>.txt + 实例 .map 自动复制 + QManage 注入

### 5. `_map_header_labels` / `_spawn_is_explicit_header` —— 刷怪表格（本轮已融合 ✅）
- 表格列：map / x / y / monster / range / count / time（+ 元歌加地图名）
- 元歌实现：`spawnTable(root, {map, mon, limit})` → 结构化行数据 + GUI 表格渲染

### 6. `_spawn_atomic_write` —— 原子写入 + 防覆盖（P1-3 已融合 ✅）
- identity（st_dev/st_ino/st_size/st_mtime_ns）+ SHA256 双校验，其他程序改动则拒绝覆盖
- 元歌实现：atomicWrite（临时文件+rename）；identity/SHA256 校验可选增强

### 7. `_read_text_with_encoding` —— 多编码（已融合 ✅）
- utf-8 / gbk / gb18030 / big5 / mbcs 自动检测
- 元歌实现：detectEncoding（BOM + utf8 往返 + gb18030）
