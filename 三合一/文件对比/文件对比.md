# 文件对比 —— 三家实现专题

> 文件/目录差异对比（仅A/仅B/相同/行级差异）

## 一、来源

**虾米**。虾米基础工具含"文件对比"。

## 二、元歌工具箱实现

**函数**（rate-tool/lib.js）：`compareDirs/compareTextLines`

**CLI**：
```
元歌工具箱-CLI.exe cmp <目录A> <目录B> [--max 行数]
```

**GUI**：文件对比面板（🔀）：目录A/B + 对比按钮。

**实测**：真实端 vs 副本：仅A 7 / 相同 1362 / 不同 904。

## 三、三家证据

- **蜗牛**：未发现文件对比功能
- **快捷助手**：未发现文件对比（文本搜索为主）
- **虾米**：基础工具含"文件对比"（文本搜索/文件对比页）
