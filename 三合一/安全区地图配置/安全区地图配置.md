# 安全区/地图配置 —— 三家实现专题

> 地图配置 = 安全区（StartPoint.txt）+ 地图属性（MapInfo.txt）+ 小地图（MiniMap.txt）。
> 开区常用：调安全区范围/出生点、加传送门、改地图属性（SAFE/NORECALL）、绑小地图编号。

---

## 一、功能是什么

- `StartPoint.txt`：安全区/出生点（`地图 X Y 范围 类型 附加...`）——翎风"地图代码不区分大小写"、"安全区光环代码：2"
- `MapInfo.txt`：地图配置（`[地图代码|标题 属性...]` + 传送门 `源地图 X,Y -> 目标地图 X,Y`）——属性：SAFE/NORECALL/NODEAL/NODRUG/ONKILLMON KillFUNC(1)/NOALLOWUSEITEMS(...)/NOTALLOWUSEMAGIC(...)/INCHP(1/1000) 等
- `MiniMap.txt`：小地图绑定（`地图代码 小地图编号`）

## 三、元歌工具箱实现

**函数**（rate-tool/lib.js）：
- `readStartPoint/writeStartPoint/addStartPoint/delStartPoint`：安全区增删查——实测 **21 个**
- `readMapInfo`：地图属性 + 传送门解析（支持过滤搜索）——实测 **530 地图 + 1647 传送门**
- `readMiniMap/writeMiniMap`：小地图读写——实测 **325 条**

**CLI**：
```
元歌工具箱-CLI.exe mapcfg <根> --start                # 安全区列表
元歌工具箱-CLI.exe mapcfg <根> --start --add 3 330 331 0 10   # 加安全区
元歌工具箱-CLI.exe mapcfg <根> --start --del 3 330 331       # 删安全区
元歌工具箱-CLI.exe mapcfg <根> --mapinfo --filter 地图代码    # 搜地图属性
元歌工具箱-CLI.exe mapcfg <根> --minimap              # 小地图列表
```

**GUI**：地图配置面板（🗺️）——安全区/地图属性/小地图切换 + 添加/删除/过滤。

**真实端实测**：`[0139\t新人地图] ONKILLMON KillFUNC(1) SAFE NORECALL`、`YMZL1 6,41 -> YMZL3 13,48` 等解析正确。
