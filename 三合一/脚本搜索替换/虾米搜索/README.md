# 虾米搜索 —— 逆向证据 + 元歌对照

> 虾米工具箱「文本搜索 / 文件对比」，及元歌工具箱的对照。
> 完整证据见 `证据-stream0014字符串.txt`。

## 一、原版逆向结论

**模块**：主程序「基础工具」栏（文本搜索/端口配置/货币兑换/文件对比）

```
[文本搜索] 基础工具 选择服务端根目录 集中处理 文本搜索 端口配置 货币兑换 文件对比
[文本搜索] 文本搜索 basicSearchPanelTitle 范围
[文件对比] 根目录确认后可切换到搜索/对比
```

**关键设计**：文本搜索 + 文件对比 共用"选择服务端根目录"工作区（基础工具统一入口）。
