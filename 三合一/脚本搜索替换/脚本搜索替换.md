# 脚本搜索替换 —— 三家实现专题

> 脚本搜索替换：Envir 目录遍历搜索/替换，还原自蜗牛/快捷助手/虾米。

## 一、功能

1. 目录遍历（含子目录、区分大小写、文件类型过滤）
2. 搜索/替换双模式（替换空 = 删除）
3. 5 种匹配模式：精确/包含/正则/前缀/后缀
4. 结果含文件路径 + 行号，可打开查看

## 二、三家实现对比（详见各子目录 README）

| 实现 | 机制 | 状态 |
|---|---|---|
| **蜗牛** | index-0a99aa24：form 表单 + 搜索/替换 + 行号 | 元歌按其复刻 ✅（含正则增强） |
| **快捷助手** | 文本搜索 + 热键查看（exe @14162） | 热键可借鉴 ⏳ |
| **虾米** | 文本搜索 + 文件对比（基础工具统一入口） | 方向一致 ✅ |

## 三、元歌工具箱实现

**函数**（rate-tool/lib.js）：`searchScripts / replaceScripts`（matchMode: exact/contain/regex/prefix/suffix）

```
元歌工具箱-CLI.exe grep <引擎根> <关键词> [--mode contain] [--type .txt]

```
