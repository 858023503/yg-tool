# M2 重载 —— 三家实现机制专题

> M2 重载 = 不重启引擎，让 M2Server 重新加载怪物爆率 / NPC 脚本 / 数据库等配置。
> 三种实现思路：**Win32 菜单点击**（蜗牛/快捷助手）、**进程重启**（部分工具）、**占位**（虾米）。

---

## 一、为什么"重载"这么难？

M2Server（翎风/gee/gom 等引擎）的"控制-重新载入"菜单是 **Delphi 原生菜单**，没有对外接口。第三方工具只能：
1. **模拟点击菜单**（Win32 API：FindWindow 找窗口 → GetMenu 枚举菜单 → PostMessage WM_COMMAND）——最通用；
2. **重启 M2Server 进程**——粗暴但有效；
3. **M2 插件**（PlugList.txt 注册 DLL，插件开端口/消息接收命令）——需要 M2 支持且要装插件。

**关键难点**：M2 主窗体（`TfrmMain`）在**翎风引擎控制台（GameCenter）里是以子窗口嵌入的**（"服务窗口" TabSheet 内）——`EnumWindows` 顶层枚举**找不到**它，必须 `EnumChildWindows(GameCenter窗口)` 才能发现带菜单的主窗体。

## 二、三家实现对比

### 1. 蜗牛实用工具（Electron + V8 字节码）
- **机制**：main 进程字节码内含全套 Win32 FFI 调用：`FindWindowA/W`、`SendMessageA/W`、`PostMessageA`、`GetMenu`、`GetMenuItemID`、`GetSubMenu`、`GetMenuStringA`。
- **流程**：FindWindow 找 M2 窗口 → GetMenu 枚举"控制-重新载入"菜单 → 按菜单项发 `WM_COMMAND`。
- **局限**：依赖 M2 窗口可见；托盘模式下主窗体未创建则失效。
- 证据见 `蜗牛m2重载/`。

### 2. 传奇服务端快捷助手（VB6 + UPX 壳）
- **机制**：同样的 Win32 菜单点击。导入表：`FindWindow/FindWindowEx/EnumWindows/GetWindowThreadProcessId/GetMenu/GetSubMenu/GetMenuItemID/GetMenuString/PostMessage/SendMessage/ShellExecute/WinExec`。
- **命令表 16 项**：怪物爆率=ReloadMonItems、怪物数据库=ReloadMonsterDB、物品数据库=ReloadItemDB、小地图配置=ReLoadMinMap、NPC脚本=ReloadNpc、机器人脚本=ReloadRobot、机器人配置=ReloadRobotManage、管理员列表=ReloadAdmin、开关拿沙=ForcedWallconquestWar、改变城主=ChangeSabukLord、删除行会=DelGuild、建立行会=AddGuild、查询地图怪物=MobCount、复活人物=ReAlive、踢掉人物=Kick、杀死人物=Kill。
- **UI 元素**：引擎下拉 + "重新加载"按钮 + "显示M2窗口标题" + "含有该关键字的M2才执行（留空=所有M2）" + "跨桌面重载（需每个桌面启动一个本程序）" + 机器人。
- **本质**：命令表里的"ReloadMonItems"等是逻辑标识，实际发送仍是**菜单项文本匹配 → WM_COMMAND 点击**。
- 证据见 `快捷助手m2重载/`。

### 3. 虾米工具箱（Python 3.8 + PySide2）
- **机制：Win32 菜单点击（含懒加载预热，三家中最完善）**。主程序 `stream_0014.pyc`（2.58MB，`工具箱_qt.py`）内含完整实现：
  - 点击"重载"按钮 → `_run_reload_menu_leaf_async`（QThread）→ `_ReloadMenuLeafWorker.run` → `_win_send_menu_path`
  - 路径式遍历：`_split_menu_path` 按 `>` 拆分"控制>重新加载>怪物爆率" → `GetMenu/GetMenuItemCount/GetSubMenu/GetMenuStringW/GetMenuItemID` 逐级定位
  - **懒加载预热**：`_try_warm_up_menu_path` 先发 `WM_INITMENU`/`WM_INITMENUPOPUP` 让 Delphi 菜单初始化（关键细节）
  - 发送：`_try_send_wm_command` → `SendMessageW` / `SendMessageTimeoutW`（带超时防卡死）→ `WM_COMMAND`（cmd_id=low16 菜单ID）
  - 菜单项 defs：QManager / QFunction / 所有NPC / 怪物爆率 / Robot 机器人脚本 / 物品数据库 / 技能数据库 / 怪物数据库 / 怪物说话设置 / 怪物大血条 / 宝箱数据 / 数据列表
  - 错误提示：ctypes不可用 / 窗口句柄无效 / 窗口无菜单 / 菜单路径为空 / 未找到菜单 / 菜单无子项 / 菜单项不可触发 / 发送失败
- **结论**：真实实现，实测生效。**元歌已吸收其"懒加载预热"改进**（m2-reload.ps1 加 WM_INITMENU/WM_INITMENUPOPUP 预热）。
- 证据见 `虾米m2重载/`。

## 三、元歌工具箱的实现（最终版，已实测可用）

**文件**：`m2-reload.ps1`（PowerShell 调 Win32，CLI/GUI 共用；SEA 单文件内联）

**机制**：
1. 找 `GameCenter`/`M2Server` 进程；
2. `EnumWindows` 枚举顶层 + 对每个顶层 `EnumChildWindows` 枚举子窗口（**子窗口按 PID 过滤**，避免误中 DBServer）；
3. 找带菜单（`GetMenu != 0`）且类名含 `Main/Form` 的窗口（即 M2 的 `TfrmMain`）；
4. 枚举菜单：顶级"控制(&C)" → 子菜单"重新加载(&R)" → 菜单项列表；
5. 匹配（去 `&`/空格/括号精确匹配 → 包含匹配 → 关键词映射：`NPC脚本`→`所有NPC`、`机器人脚本`→`Robot 机器人脚本`、`QManage`→`QManage 登录脚本`）；
6. `PostMessage(M2窗口, WM_COMMAND=0x111, 菜单ID, 0)` 模拟点击。

**翎风 M2 实测**（"翎风01 [无限版]"）：
- 22 项可用：物品数据库(4)/技能数据库(5)/怪物数据库(6)/怪物说话设置(7)/怪物大血条(8)/宝箱数据(9)/数据列表(10)/地图安全区(11)/参数设置(12)/物品掉落规则(13)/QManage 登录脚本(15)/QFunction 功能脚本(16)/QMission 任务脚本(17)/QChatbox 聊天框脚本(18)/Robot 机器人脚本(19)/所有NPC(20)/地图事件触发(22)/怪物爆率(25)/摆摊物品最低售价(27)/出售角色其他信息(28)/假人列表(30)/授权RunGate网关IP文件(32)
- 实测：`怪物爆率 → PostMessage=True`、`所有NPC → PostMessage=True` 等全部成功。

**使用方法**：
```
# CLI
元歌工具箱-CLI.exe m2reload --list                        # 列出 M2 实际重载菜单项
元歌工具箱-CLI.exe m2reload --item 怪物爆率                # 重载怪物爆率
元歌工具箱-CLI.exe m2reload --item "NPC脚本"               # 重载所有NPC（关键词映射）

# GUI
左侧导航 → M2 重载 → 下拉选项目 → 执行重载 / 列出 M2 菜单
```

**注意**：需 M2 已通过引擎控制台启动（窗口嵌入"服务窗口"）；若提示"未找到菜单"，请在引擎控制台"服务窗口"确认 M2 标签已打开。
