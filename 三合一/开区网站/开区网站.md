# 开区网站 —— 三家实现专题

> 静态开区宣传 HTML（5 皮肤）

## 一、来源

**蜗牛**。蜗牛内置 HTTP 服务生成版本查询网站（新区/快餐服/单职业，5 皮肤，LOGO/群号/按钮/缓存）。

## 二、元歌工具箱实现

**函数**（rate-tool/lib.js）：`genOpenSite/SITE_SKINS`

**CLI**：
```
元歌工具箱-CLI.exe site <引擎根> [--title 标题] [--skin dark|gold|blue|green|light] [--new 新区] [--fast 快餐] [--solo 单职业]
```

**GUI**：开区网站面板（🌐）：标题/皮肤/三区段 + 生成。

**实测**：生成 1605B HTML（gold 皮肤）。
