# 虾米快捷工具 —— 逆向证据 + 元歌对照

> 虾米工具箱「快捷工具」，及元歌工具箱的对照。
> 完整证据见 `证据-stream0014字符串.txt`。

## 一、原版逆向结论

**模块**：主程序「快捷工具」导航

```
[快捷工具] 快捷工具
[快捷] 欢迎参加限时活动<进入/go>  替换版本内占用变量  快捷组队
[快捷] 文件: QFunction...  QuestDiary\活动
[快捷] 快捷方式启动后没有返回 PID  请用 PID 接入监控
```

**关键设计**：快捷组队/活动入口 + 变量替换 + PID 监控（快捷方式启动后监控进程）。

## 二、元歌对照

| 对比项 | 虾米 | 元歌 |
|---|---|---|
| 形态 | 快捷组队/活动入口（脚本注入式） | 快捷文件 + NPC 列表（蜗牛形态） |
| PID 监控 | 有（启动后监控） | 未做 |

**可借鉴（未融合）**：快捷方式启动后 PID 监控——元歌暂无此需求。
