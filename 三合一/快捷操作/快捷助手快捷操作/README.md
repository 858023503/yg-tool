# 快捷助手快捷操作 —— 逆向证据

> 传奇服务端快捷助手 V2025-10-01（VB6 + UPX 加壳）的快捷操作功能核查。

## 一、逆向结论：快捷助手**有文件排版/快捷打开**

**证据**（`证据-exe与ini.txt`）：
```
[ini] 文件排版=@!\Mir200\Envir\MerChant.txt*自定义NPC|@!\Mir200\Envir\Npcs.txt*内置NPC|@!\Mir200\Envir\MonGen.txt*刷怪|@!\Mir200\Envir\StartPoint.txt*安全区|...
[exe] 文件排版（支持文件拖入）
```

**关键设计**：ini 配置「文件排版」列表（路径*显示名），支持文件拖入排序——与蜗牛"快捷文件"同思路。

## 二、对元歌的借鉴

- **文件拖入**（拖文件到排版列表自动加入）——元歌快捷文件为固定模板，可加拖入支持
