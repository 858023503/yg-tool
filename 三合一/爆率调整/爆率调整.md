# 爆率调整 —— 三家实现专题

> 爆率调整：传奇服务端核心工具（MonItems 爆率文件编辑），还原自蜗牛/快捷助手/虾米。

## 一、功能

1. **爆率查看/追加/删除**：全服 / 按地图 / 按怪物名 三维定位 → 追加/删除物品爆率
2. **倍数调整 / 随机爆率**：概率×N、转 `#CHILD 1/1 RANDOM`（保持原分子）
3. **整体优化**（虾米借鉴）：方法筛选（怪物/地图/物品）+ 范围匹配（den>N）+ 加减乘除设值
4. **批量新增 / #CALL 还原**（虾米借鉴）：物品列表批量追加、引用展开（防穿越/防备份）
5. **备份/还原**：写前自动备份到 `@backup/`，一键还原

## 二、三家实现对比（详见各子目录 README）

| 实现 | 机制 | 状态 |
|---|---|---|
| **蜗牛** | 爆率系统 rate.*：三维定位 + 追加/删除/倍数/随机 + MonGen 反查 + 爆率模拟器 | 最完善，元歌按其复刻 ✅ |
| **快捷助手** | **无爆率编辑**（仅 ReloadMonItems 重载命令，脱壳字符串 0 命中爆率关键词） | 无借鉴 ❌ |
| **虾米** | `_MonItemsAddWorker` 批量新增 + `_drop_resolve_call` #CALL 还原 + droprate.json 查询 | 批量/还原已融合 ✅ |

## 三、元歌工具箱实现（三合一融合）

**函数**（rate-tool/lib.js）：

```js
readMonFile / writeMonFile        // MonItems 解析 + GBK 写回（保留注释/空行）
addRate / delRate                 // 追加/删除爆率
globalOp({type, name, mode})      // 全服/按地图/按怪物 操作
randRate()                        // 随机爆率转换
overallOptimize({method, op, opValue, rangeOp})   // 整体优化（虾米）
addRates({items, rate, target})   // 批量新增（虾米 _MonItemsAddWorker）
resolveCall / restoreCall()       // #CALL 还原（虾米 _drop_resolve_call）
backupMonItems / listBackups / restoreBackup      // 备份还原
detectEncoding(buf)               // 多编码检测
```

**融合点标注**：
- 蜗牛 → 三维定位 + 四种操作 + 随机爆率（核心）
- 虾米 → 整体优化 + 批量新增 + #CALL 还原 + 多编码（增强）
- 快捷助手 → 无

**写安全**：写前自动备份 + 多编码检测 + 保留注释/空行
