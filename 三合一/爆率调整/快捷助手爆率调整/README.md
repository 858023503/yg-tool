# 快捷助手爆率调整 —— 逆向证据

> 传奇服务端快捷助手 V2025-10-01（VB6 + UPX 加壳）的爆率功能核查。

## 一、逆向结论：快捷助手**无爆率编辑**功能

**证据**：

1. **重载命令表 16 项**（脱壳后字符串提取，详见 `三合一\m2重载\快捷助手m2重载\README.md`）：
   ```
   怪物爆率    ReloadMonItems     ← 只有"重载"命令，没有编辑
   怪物数据库  ReloadMonsterDB
   物品数据库  ReloadItemDB
   ...
   ```
2. **字符串扫描**（UPX 加壳段之外）：
   - ASCII：`MonItems / #CHILD / RANDOM / 爆率 / drop` → **0 命中**
   - UTF-16LE（VB6 Unicode）：同上 → **0 命中**

**结论**：快捷助手仅提供 `ReloadMonItems`（M2 重载怪物爆率），**不包含爆率编辑/调整功能**。
