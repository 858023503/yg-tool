# 回收生成 —— 三家实现专题

> 回收生成：生成「勾选界面 + 总开关 + 全选/反选 + 一键回收」NPC 脚本，还原自蜗牛/快捷助手/虾米。

## 一、功能

1. 分类配置：分类名/颜色/提示/回收物品（多选/搜索/拖拽）
2. 给予配置：金币/元宝/金刚石/灵符/自定义货币（货币名|变量名）/给予物品
3. 生成：[@元歌一键回收] → [@元歌回收列表] → [@元歌单项回收N]（MUL/GIVE/INC 命令）
4. 去私货：无 QQ 引流、品牌「元歌」

## 二、三家实现对比（详见各子目录 README）

| 实现 | 机制 | 状态 |
|---|---|---|
| **蜗牛** | index-f056a783 明文 JS：勾选界面 + 一键回收 + 自定义货币 | 元歌完整复刻 ✅ |
| **快捷助手** | **无回收生成**（无证据） | 无借鉴 ❌ |
| **虾米** | _generate_recycler + loadSettings/saveSettings 设置持久化 | 持久化可借鉴 ⏳ |
