# 蜗牛回收生成 —— 逆向证据 + 元歌实现

> 蜗牛实用工具「回收生成」（index-f056a783 明文 JS），及元歌工具箱的完整复刻。
> 完整证据见 `证据-REVERSE-REPORT.txt`。

## 一、原版逆向结论

**脚本结构（renderer 片段还原）**：
```
[@元歌一键回收] → [@元歌回收列表] → [@元歌单项回收N]
```

**关键命令**：
```
MUL N$元歌回收货币N <$STR(N$元歌回收数量)> 价格
GIVE 金币/物品 或 INC 自定义变量
```

**表单**：分类名称/颜色、回收装备（多选/搜索/拖拽排序）、回收给予（金币/经验/自定义货币「货币名|变量名」/给予物品名+数量）、每行显示列数、素材（背景/勾选/未选 wil 编号）、版本类型（凌风系/GOM系）

**交互**：勾选界面 + 总开关 + 全选/反选 + 一键回收

## 二、元歌实现（已融合 ✅，含去私货）

```js
// rate-tool/lib.js
genRecycleScript(root, opts)   // 回收 NPC 脚本生成（[@元歌一键回收] 结构）
addRecycleNpc(root, o)         // NPC 文件写入（MerChant.txt）
allocFlags(used, n)            // 个人标识自动分配（防冲突）
INJECT_MARK = ';@@yge-inject:' // 注入标记（原版 ;@@snail-inject: 已去私货改元歌）
```

**去私货**：原版生成的 QQ 引流注释（群号/蜗牛品牌）已移除，品牌统一「元歌」。
