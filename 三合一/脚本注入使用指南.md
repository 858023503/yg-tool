# 元歌工具箱 · 脚本注入功能使用指南（GUI 操作）

> 用途：把元歌群服脚本的 QF/QM 触发片段注入到引擎端（QFunction-0.txt / QManage.txt），
> 让元歌脚本的功能（天赋/挂机/超武/赞助/特效）在目标端生效。
> 注入源：D:\cqzs\元歌脚本\元歌整合资源\qf添加.txt + qm添加.txt（主仓库维护，已做注释修正）。

## 一、前置准备

1. **元歌脚本目录**：把 D:\cqzs\元歌脚本（主仓库）里的内容部署到目标端的 Mir200\Envir\QuestDiary\元歌脚本（部署步骤参考《元歌群服搭建教学.txt》：步骤 6）
2. **素材/配置**（按搭建教学步骤 1-5）：pak.txt、EffectImageList.txt、GroupItemList.txt、ItemRuleList.txt、ItemDescList.txt 的追加项（这些用 GUI 的「脚本注入」面板目标选对应列表即可，或手动加）
3. **本指南只讲 QF/QM 的脚本段注入**

## 二、GUI 操作步骤

### 第 1 步：选引擎根
- 打开元歌工具箱，顶部「服务端根 / Mir200 / Envir」输入框 → 填目标端根目录（如 D:\传奇本地版本\MirServerBULUTUO），或点「📁 浏览」选择
- 确认是 **MirServer 根**（含 Mir200 目录），不是上级目录

### 第 2 步：打开「脚本注入」面板
- 左侧导航「🛠 服务端工具」→「📥 脚本注入」

### 第 3 步：注入 QF（QFunction-0.txt）
| 项 | 填什么 |
|---|---|
| 注入名称 | 元歌群服QF（防重复检测用，保持固定） |
| 注入目标 | 选 **QFunction-0.txt（Market_Def）** |
| 注入模式 | **追加注入**（append） |
| 变量替换 | 不勾选（元歌变量是自定义 N$/S$/HUMAN，一般无冲突；若报变量冲突再勾选） |
| 脚本内容 | 粘贴 qf添加.txt 的**全部内容**（用 Notepad++ 打开，GBK/ANSI 编码，全选复制） |

点「执行注入」→ 底部提示如「注入「元歌群服QF」：段合并 8、新增 5 → ...QFunction-0.txt」

### 第 4 步：注入 QM（QManage.txt）
| 项 | 填什么 |
|---|---|
| 注入名称 | 元歌群服QM |
| 注入目标 | 选 **QManage.txt（MapQuest_Def）** |
| 注入模式 | **追加注入** |
| 脚本内容 | 粘贴 qm添加.txt 的**全部内容** |

点「执行注入」→ 提示「段合并 1、新增 2」等

### 第 5 步：检查
- 提示「已注入过」= 该端之前注入过（append 防重复，说明已存在，无需重复注入）
- 提示「段合并 X、新增 Y」= 成功：X 个段合并进已有触发段，Y 个新段追加

### 第 6 步：收尾
- **重启 M2** 生效
- 游戏内验证：登录触发（杀怪点/倍率）、攻击/魔法特效、按钮、GM 命令

## 三、注意事项

1. **只对没注入过的端跑一次**。如果端之前手动复制过元歌脚本（如 v3 怀念端的历史样本），再注入会把 qf 内容**追加一遍**（触发段里 #CALL 重复，元歌逻辑执行两次）。判断方法：注入前用文本打开目标 QFunction-0.txt，搜 ;@@yge-inject:——有则已注入过（工具注入），无需再跑。
2. **注入内容编码**：qf添加.txt / qm添加.txt 是 **GBK**。粘贴到 GUI 时保持编码一致（GUI 内部按 GBK 写入，直接粘贴文本即可）。
3. **城隍（v5 类）特例**：城隍 QF/QM 没有标准触发段（[@Attack]/[@Login] 等），注入会**全部追加**（合并 0），且城隍引擎**可能不触发**这些追加段 —— 需真端验证，若无效则城隍端暂不适用元歌脚本。
4. **元歌脚本目录必须已部署**到 QuestDiary\元歌脚本，否则 #CALL 找不到目标文件。
5. **模板库**：可以把 qf添加.txt/qm添加.txt 存为模板（面板「💾 存为模板」），下次「📂 载入」直接用。

## 四、常见结果解读

| 提示 | 含义 |
|---|---|
| 段合并 8、新增 5 | 8 个触发段（[@Attack]/[@MagicAttack] 等）合并进已有段末尾；5 个新段（[@ButtonClick43] 等）追加到文件尾 |
| 已注入过 | 该名称已存在标记，append 模式防重复（不重复注入） |
| 内容已全部存在 | 列表类目标（素材/分组等）逐行已存在，跳过 |
| 注入内容未解析到段 | 内容里没有 [@段名]，检查是否贴了完整文件 |
